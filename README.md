EventConnect is a web-based event staffing platform that connects event organisers with candidates looking for temporary event opportunities.

## About the Project

Finding people to manage events can be challenging for organisers, while candidates often struggle to discover temporary event work.

EventConnect provides a simple platform where organisers can publish event opportunities and candidates can apply directly.

## Features

### Candidate
- Explore available event opportunities.
- View event details.
- Apply for events with personal and professional details.
- Submit a resume URL.

### Organiser
- Create and publish event opportunities.
- View candidates who applied.
- Review candidate details and resumes.
- Accept or reject applications.
